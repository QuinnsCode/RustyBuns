## Stop 1: the box office
- Press "Sign in" :: You press it inside the game. :: a game screen with a sign-in button
- The game sends you to eqosys :: You leave the game for a moment. :: an arrow from the game to a box office
- Sign in there, never in the game :: Your password goes only to eqosys. :: a password typed at the box office window
- Back with a one-minute code :: eqosys sends you back with a short code that works for one minute. :: a small slip with a tiny clock
- Only the game that asked can swap it :: The code is no use to anyone else. :: a slip that fits one slot only
- The code becomes a ticket :: The game swaps the slip for a proper ticket. :: a slip going in, a ticket coming out
- Nothing to lose :: The game never sees your password. It cannot lose what it never had. :: an empty safe with the door open
- Not signed up yet? :: A friend's link signs you up first, then brings you straight back. :: a loop from a link to sign-up and back to the game

## The ticket
- What the ticket says :: Who you are, which app, what you may do, and until when. :: a ticket with four lines on it
- Who :: Your account, not your password. :: a name on the ticket, no password
- Which app :: A ticket for one game does not open another. :: a ticket that fits one door, not the next
- What you may do :: Player, tester or maker: what this app lets you do. :: three stamps on a ticket
- Until when :: It runs out soon, and a fresh one comes quietly. :: a ticket with a fading edge and a new one behind it
- A secret stamp, a public checker :: eqosys stamps every ticket. It shows everyone how to check the stamp. :: a stamp in a locked drawer, a checker on the counter
- The room checks it alone :: A game room never phones eqosys to ask "is this real?". :: a doorman checking a ticket, a phone left on the hook
- Like a banknote hologram :: The shopkeeper checks it at the till. Nobody calls the bank. :: a banknote held to the light at a till
