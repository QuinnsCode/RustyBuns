# The Frankenstein Code Factory
> A code home that runs, copies and changes itself, with a person in the loop at every turn.

## The picture: a bakery that bakes its own ovens

- Most bakeries buy their ovens :: This one bakes them. :: an oven arriving on a truck, crossed out; an oven rising out of dough
- The book holds the oven's recipe too :: The recipe book has bread recipes, and one recipe for the oven itself. :: an open book: a bread page and an oven page

## Four parts, stitched together
- Four parts, one body :: A code home, an office of helpers, a sealed room and an engine. :: four labelled body parts on a workbench
- codeSplitter: the recipe book :: The place where the code lives. It remembers every line and who wrote it. :: a thick recipe book with name tags on the pages
- Agent Office: the kitchen :: A 3D office where AI helpers sit at desks. Made by WebDevCody, shared under MIT. :: a small 3D office with helpers at desks, a credit line under it
- The sandbox: one door and a guard :: A sealed room. A program inside can touch only what you list. :: a kitchen with one door and a guard at it
- Rusty Buns: the lunchbox :: Our engine. It turns an app into one file that runs on a laptop, a server or the cloud. :: one lunchbox on three different tables
- Why "Frankenstein" :: Someone else's body. Our engine. Our game's faces. The stitches show on purpose. :: three stacked layers: skin, body, heart

## codeSplitter: every line wears a name tag
- Files are the wrong size :: Normal code storage thinks in files. Two helpers in one file trip over each other. :: two hands pulling one sheet of paper
- Every line wears a name tag :: Each line gets its own tag: who wrote it, and its history. :: lines of text, each with a small paper tag
- Three helpers, one file, one moment :: They change one file at the same time. Nobody overwrites anybody. :: three coloured cursors in one file
- Still real git underneath :: The usual tools still work. Nothing to learn to read it. :: name tags on top, a plain git history below
- Edit by shape :: One change lands in every file that needs it, in the form each file needs. :: one surname changed on every form in a stack
- Files that move together get tested together :: We know which files changed as a group, so we test the group, not everything. :: three boxes: edit by shape, move as a group, test what it touches

## The loop: the factory changes itself
- The book holds the oven :: codeSplitter stores the office's code, and its own code too. :: a book with a picture of the same book on its cover
- Helpers can change their own office :: They can open the code of the office they sit in, and improve it. :: a helper repainting its own desk while sitting at it
- Copy :: A fresh copy of the office starts in a sealed box. :: a loop diagram with step 2 lit: a new copy in a box
- Change, then check :: Helpers change the code. Tests run. Then a person reads it. :: loop steps 3 and 4 lit: helpers, then a person with a magnifier
- Swap :: The new copy goes in. The old copy goes out. The loop starts again. :: the full five-step loop, step 5 lit
- Tools that make tools :: Each turn leaves the shop better stocked. We are on toaster number forty. :: a robot building a robot building a toaster

## Why this does not end like the movie
- A person presses deploy :: A helper can write code. It cannot ship it. :: a person's hand over a big button
- Unread code never ships :: Not even with the owner's own key. :: a pull request with a "read" stamp
- Secrets behind a fingerprint :: They unlock only when the owner touches the sensor. :: a fingerprint on a sensor, a padlock opening
- Every helper has a budget :: Stuck twice the same way? It stops and leaves a four-line note: done, next, broke, don't. :: a note card with four short lines
- What is alive, what is in the oven :: Live: codeSplitter, the office in a box, the crew. In the oven: rings, the office inside codeSplitter. :: three green tags, two amber tags, one grey
- It's alive. It also asks first. :: Thank you to WebDevCody for the body, and to the skeletons for working weekends. :: the stitched loaf from slide one, wearing a name tag
