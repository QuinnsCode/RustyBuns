# Qollab
> Friends, parties and spaces: the multiplayer every game ends up building, built once, that steps aside when play starts.

## The phone lines between houses

- Every studio wrote a lobby :: Every one of them swore it would be the last. :: a stack of near-identical lobby screens

## Qollab gets you in the door, then it leaves
- The game never goes through Qollab :: The game loop, the physics and the netcode stay in the game. :: a road that bypasses a toll booth
- The game's things stay in the game :: Decks, levels and items belong to the game. :: a game box with its own locked drawer
- It never slows a game down :: Qollab is not in the way once play starts. :: an open road with no barrier
- Change engines without asking :: A game can swap its engine and Qollab does not mind. :: a mechanic swapping an engine, a doorman shrugging
- A good host :: Introduces you, refills your drink and leaves you alone. :: a host making an introduction and stepping away
- Many small memories :: Not one giant switchboard. One small memory for each hub, party and space. :: many tiny switchboards instead of one huge one
- Each minds its own business :: A busy party never slows a quiet space. :: one lit switchboard among calm ones
