# eqosys
> One account for every app: your games, saves, achievements and friends in one home, and privacy you can press.

## A library card for every branch
- eqosys :: One account for every app. Your games, saves, achievements and friends, in one home. :: a library card with a small orbit around it
- One card, every branch :: It works in every library in town. :: one card, a row of library doors
- Every branch knows your name :: Show the card and you are known. :: a librarian smiling and waving
- Your history follows you :: What you borrowed and what you finished go with you. :: a trail of books behind a walker
- Lose the card, keep the history :: Your history is not on the card. It is safe at the main desk. :: an empty card beside a full ledger at a desk
- Who you are, not who you are with :: eqosys is who you are. Qollab, next talk, is who you are with. :: two labels: "you" and "your friends"

## Five things, one account
- Five things, one account :: Sign-in, library, saves, achievements, friends. :: five drawers in one cabinet
- Sign-in :: Email and password, or a big button you already use. Add more than one; every device opens the same account. :: three keys on one key ring
- Your library :: Every game you play, the one you played last, and what to pick up again. :: a shelf of game boxes, one pulled half out
- Saves :: Your saves in the cloud. The last few copies are kept, so a bad save is not the end. :: a stack of save cards, newest on top
- Achievements :: Badges from every game, on one shelf. :: a shelf of badges
- Friends :: Who you play with, and what they are playing now. :: a small list of faces with a "playing" dot beside some

## A friend gets in with one link
- You send your link :: One link, from you to a friend. :: a link passed hand to hand
- No account? Make one on the spot :: The link opens sign-up when it needs to. :: a door that opens to a short form
- One tap, and you are friends :: No email, no request to wait on. :: a single tap on a button
- They still say yes :: Opening the link alone makes nobody your friend. :: a door that opens only from inside
- Straight back to the game :: After sign-up, the link takes you back to where you started. :: a loop arrow from a game to sign-up and back
- A dare is the best form :: The best sign-up form is one your friend fills in because you dared them. :: a friend grinning at a phone

## Saves we keep, but never read
- A coat check for progress :: We give you a ticket. We do not go through the pockets. :: a coat check counter, a ticket handed over
- Sealed when it arrives :: A game hands eqosys a save. eqosys keeps it sealed. :: a sealed envelope dropped into a box
- Size and time, nothing more :: eqosys only knows how big a save is and when it came. :: an envelope with only a weight and a date on it
- A bad save is not the end :: The last few copies are kept. :: a stack of envelopes, the top one torn
- Two devices at once? You pick :: The game can show you both saves and let you choose. :: two envelopes, a hand choosing one
- Saves follow you :: Start on one device, carry on from another. :: a save card passing from a laptop to a phone

## Privacy you can press
- Leaving as easy as arriving :: Ideally with less paperwork. :: an open door with a welcome mat on both sides
- Download it :: One button gives you everything eqosys holds about you, in one file. :: a single file sliding out of a box
- Kept near you :: Your data stays in your part of the world. :: a map with a pin near home
- Delete it :: One button removes the account. Every room and friend hears you left. :: one button, small ripples spreading
- No game sees your password :: You sign in with eqosys, never in the game. :: a game screen with no password field
- Your data, your call :: Download, keep near, delete: all in your hands. :: three buttons in an open palm
