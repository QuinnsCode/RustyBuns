What Rusty Buns Is

Write an app once. Run it on a laptop, a server or the cloud.

Not rusty. Not buns. We explain the name on slide 10, and you will still not forgive us.

One idea for the whole talk: one app, three places, no rewrite. Every slide comes back to the plug picture.
The picture first

One plug that fits every socket

You travel with one lamp. Every country has a different socket.

  • Most people buy a new lamp in each country.
  • Some people carry a bag of adapters, and lose one every trip.
  • Rusty Buns is a plug that changes shape to fit the wall. The lamp stays the same.

The lamp is your app. The wall is wherever it has to run. The plug is our problem, not yours.

The three sockets

Where one app can run

On a laptop

One file you double-click. The app opens in your browser. Your data stays on your machine.

Like: cooking at home.

On a server

The same file on one rented computer. Cheap, and you can hold many small apps there.

Like: a stall in the food hall.

In the cloud

On Cloudflare, close to every visitor. Nobody looks after a server.

Like: a chain with a shop on every corner.

The middle card is "the box" from talk 0. Say the word once.
Why this is hard

Each socket speaks a different language

A laptop keeps data in a file. The cloud keeps it in a database far away. A server is somewhere between.

  • Usually you write the app once for each place.
  • Then you fix each bug three times.
  • Then the three copies slowly stop agreeing.

Three copies of one app is not a backup plan. It is a hobby.

The trick

Five parts, and a twin for each one

Almost every app with a server needs the same five parts.

The front door

Requests come in. Answers go out.

Live messages

Fast talk, both ways, like a game or a chat.

Storage

Data you keep.

Memory

Fast data a restart throws away.

Who you are

Sign-in.

Cloudflare gave each part a simple shape. We gave each shape a twin that runs on your laptop. Same shape, different socket.

This is the "cute specific" for the talk: you write against the cloud's five shapes, and each shape has a local twin. Do not list the products or how the twins are made.
One list, three places

You write one short list. The tool does the rest.

Your app has no Rusty Buns code in it. If you leave, you delete one list and walk away. We would be sad, quietly.

Rust when you need it

TypeScript everywhere. Rust only for the heavy lifting.

  • Almost all of the app is TypeScript: the page, the server and the settings.
  • Some jobs are too slow for it: sound, physics, shapes, big puzzles.
  • You write only that part in Rust. It runs on a laptop, on a server, or inside the page as WebAssembly.
  • Every Rust part has a TypeScript twin that gives the same answer. If Rust cannot load, the twin takes over.

The race engine is optional. The family car still gets you to the shops.

Safe for people, safe for AI helpers

Small, and nothing costs money by surprise

  1. It runs with no cloud account. A helper can start, test and break the real app on a laptop, for free.
  2. It shows the price first. Before anything goes to the cloud, it lists every paid piece.
  3. It cleans up. One command removes everything it made.
  4. The app is a normal web page. AI helpers can see it and press its buttons.

Think of an idea at breakfast. Play it after lunch. Get the bill never, unless you said yes.

What it is not

It sits on top. It does not replace.

  • It is not a new way to write web pages. Keep the tools you like.
  • It works on top of the popular web frameworks. So we call it a framework for frameworks.
  • It does not make phone apps. A phone app should feel like the phone. The phone app can still talk to the same cloud.

A meta metaframework. Say it three times fast and a consultant appears.

The name

Why "Rusty Buns"

Rust for the fast parts. Bun for everything else. You need neither to use it.

It started with grass. A game needed faster grass, so a fast engine went behind a web page. Then the same code ran in the cloud and on a server, and the grass became a framework.

Most frameworks start with a big plan. Ours started with a lawn.
