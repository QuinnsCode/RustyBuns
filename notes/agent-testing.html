Testing Our Agents

The question: how do you test an agent when the model answers a little differently every time?

Recording real model calls and playing them back still breaks. Fake answers need their own checks, and those go stale. It seems you can't win.

Our answer: every PR plays back a recording, so it's fast, free and the same every run. Each night, the real model runs the same tests again. If the model's behaviour changes, we find out the next morning, not from a user.

The one idea

Check what the agent did, not what it said

The model's words change from run to run. The work it leaves behind should not. So our tests check the files the agent changed and ignore its wording. This is our real use-let test.

What it was given
var x = 1
function f() {
  return x
}
Task: use let
What it left: tested
let x = 1
function f() {
  return x
}
The test checks this file exactly.
What it said: not tested

"Changed var x to let x in a.js."

Tomorrow it may say this differently. The test still passes.
