What each sweep tastes

Each ring has its own sweep

The further out, the slower and broader the sweep. A release moves out when it has sat green through enough sweeps of its own ring.

PR lanes

Branch off main, squash back, one dot per PR

Every worker branches off main and comes back as one squashed commit. So each dot on main is one whole PR, and "which PR broke it" is a short walk.

main feature PR express PR red
The express lane

Straight out, or back in line

An express label (yours to set) runs every ring's sweep on that commit right away, with no waiting for the clock. Any red drops it into the normal lane at that ring, where it soaks like everyone else.
