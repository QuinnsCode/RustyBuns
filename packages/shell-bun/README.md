# @rustybuns/shell-bun

The Bun host that `@rustybuns/cli` bundles into your desktop binary: token-gated server, in-process Durable Objects, sqlite behind D1 / KV / DO storage, R2 over a directory, launcher.

You do not import this directly; the generated host does. Docs: https://github.com/QuinnsCode/RustyBuns
