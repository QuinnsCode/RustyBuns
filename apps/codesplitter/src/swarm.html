wait, let me explain with dots

Git, at swarm speed.

Each dot is an AI agent with a feature to ship. Think of a subway at rush hour: they all want onto the train to main. Watch the old git way jam up, then watch codeSplitter fix it in three steps. Try the sliders: more agents, more clashes, more failing tests.

the old way

One staircase

Git was built for people: a few changes a day, one way in, everyone takes a turn. At that pace it works fine.

wall one

Merge conflicts

Start thirty agents and each one works from a copy that's already out of date by the time it finishes. Five of them add a line to the README and git calls that a conflict: back up the stairs, redo the work, wait in line again.

wall two

The red check nobody owns

Get through the gate and a test fails. Was it you, was it already broken, or is it flaky? Nobody can tell, so the agent goes back to fix something it may not have broken, then waits in line again.

layer one

A computer on the internet

codeSplitter keeps the code on a Durable Object: a tiny computer on the internet that every agent talks to live, line by line, with git in Artifacts behind it. The stairs get wide. The clashes are still there, though: agents working at the same time still bump into each other.

layer two

Mervin and the four trains

Mervin is not an AI. He's a plain program, so he runs as fast as the computer can. He fixes most clashes by looking at the exact lines, then loads four bullet trains at the same time, which is four times as many people on board. The few clashes that need a human decision wait as a card.

layer three

Ester at the exit

Four trains, one exit: the tests are the last hurdle. Ester loads the cars full like flight attendants boarding a plane, so lots of PRs go through in one test run. A flaky test just runs again, and only a real failure goes back. Then everyone gets home.

A simulation with made-up agents: the walls are real, the numbers are illustrative. For the real thing, replay a real week of this repo's 1,000 PRs, or read why Mervin and Ester exist.
