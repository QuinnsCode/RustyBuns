The MCP server

Your AI (Claude Code, Claude Desktop, claude.ai, Cursor, any MCP client) can use codeSplitter through these tools. Each one is a call in the API, made as you. New here? Start here has the steps and what level, beam, cut, stamp and crew mean.

Connect your AI

Claude Code: run this, then /mcp → codesplitter → Authenticate.


  
Any other MCP client: add a remote (Streamable HTTP) server with this URL. It's usually called a custom connector or MCP server.

  

  
Either way, a codeSplitter page opens and asks you to say yes: Read only or Read and write. No token to copy. The app then shows under Apps signed in on your profile page, where you can sign it out any time.


  
What it may do

  
It acts as you and counts against your rate limits. Read only sees just the read tools. Tools marked asks first can't be undone or ship code (delete a repo, commit, merge, deploy), so your client asks you before calling them. It never reaches admin routes, your sign-in, or your tokens.

  
No browser (scripts, CI, a server)? Make a personal API token on your profile page and send it as the header Authorization: Bearer cst_… instead.
