How this was measured

  • Units are Claude Code transcript usage weighted at API ratios: input 1, output 5, cache write 1.25, cache read 0.1. They are relative, not dollars.
  • Savings are estimates, not meters. Ester and Dexter are each 90% of the tokens a by-hand job would have put in context (test and typecheck output; tool results over 2,000 tokens). Mervin is 90% of board, PR and CI reads plus 49% of the turns spent between a merge conflict and the commit that settled it (the rate from Mervin's replay on 400 conflicted merges). Nothing records the steps a helper actually skipped, so these move with how much the agents did, not with how well the helpers worked.
  • Hours saved (jams and red checks) are in apps/codesplitter/docs/jams.md and are not week-specific, so they are left out here.
  • Weeks are ISO weeks, Monday to Sunday. Claude Code keeps only 30 days of transcripts, so the morning job saves each day as it goes; a week before the history began shows as not recorded.
  • Code lines are source, styles, markup, SQL and shell landing on main, not docs, JSON or lockfiles. PR lines (in the day table) are what GitHub counts, everything included.
