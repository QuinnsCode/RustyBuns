The MCP server

Agents outside the browser (Claude Code, Claude Desktop, any MCP client) can use codeSplitters through these tools. Each one is a call in the API, made as you with your token.

Connect

  1. Sign in, open your profile page, and make a token in the API tokens box: Read only or Read and write.
  2. Copy the claude mcp add line it hands you, or this one with your token in it:

  
Other clients: a Streamable HTTP server at , with the header Authorization: Bearer cst_…. No sessions, no OAuth.


  
What a token may do

  
It acts as you and counts against your rate limits, until it expires (1 to 365 days). A read token only sees the read tools. Tools marked asks first can't be undone or ship code (delete a repo, commit, merge, deploy), so your client asks you before calling them. A token never reaches admin routes, sign-in, or other tokens. Revoke it on your profile page any time.
